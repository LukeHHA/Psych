## Reporting Bugs

Report bugs using the issue tracker.
Please include a Minimal Reproduction so the issue can be reproduced and inspected.
Psych currently does not have any releases and is still in early development. Therefore,
bugs must be able to be reproduced as of the latest commit.

## Pull Requests

Open a pull request for the following reasons:

- Close an issue currently listed under the issue tracker
- Propose a new engine feature
- Add documentation

When opening a PR for an issue make sure you include the issue number in the PR.
If you are proposing a new engine feature, make sure the proposal covers one feature.
PR's with multiple features should be broken into seperate PR's.

## Conduct

When updating your fork with upstream changes, use `git pll --rebase`
